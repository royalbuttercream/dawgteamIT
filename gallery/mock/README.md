## Where the photos come from

The manifest holds 1,983 photos in 22 albums, in the order the live site publishes them. It was assembled from two sources: the rendered live pages with every "Show more" expanded, and the site configuration that Strikingly inlines into every page, which carries the complete lists for six albums the rendered pages truncate at 60 (2022 Achievement Week 139, Going Away 89, Back to School 63, BlackOWT MasQUErade 168, Rooftop Brunch 71; 2017 to 2020 The Good Bruhz 580). Captions and descriptions exist for 135 photos and are carried over; the other photos get an alt of the form "Photo 12 of 60, Halloween, 2022". One album, 2021 Achievement Week, showed 61 photos in an earlier probe and 60 in the final pass; the manifest holds 60.

Image source is set in `tooling/mock-src/data/gallery-config.json`:

- `"imageBase": "cdn"` (current build): thumbnails at 480 px and large views at 1200 px are requested from the current host's image service with size transforms. Works today, depends on that host staying up.
- `"imageBase": "local"`: reads `images/gallery/<year>/<id>-t.jpg` and `<id>-v.jpg` from the repo. Switch to this once the photos are imported (see the size table in the sign-off message and `tooling/gallery-import.mjs` when it exists).

## Verification

`verify.json` in each folder. Review gate: frontend-reviewer result recorded below when complete.

### frontend-reviewer result, 23 September 2026

Four CRITICAL and four WARNING findings, all applied; four suggestions, three applied.

| Finding | Action |
|---|---|
| Every photo link was marked "opens in a new tab" by the external-link script although it opens the lightbox | Photo links carry `data-external="false"`; the script leaves them alone |
| 120 photos carried the scrape artifact "Section image" as caption and alt | Cleared from the data; those photos use the generated "Photo n of N, Album, Year" alt |
| Lightbox backdrop was a hardcoded colour | Token `--scrim` in both themes and forced colours |
| Arrow-key photo changes were not announced | The caption is an `aria-live="polite"` region and describes the image via `aria-describedby` |
| Alt text and visible caption duplicated each other | Captioned photos have the caption inside the link as the link's name and an empty alt; uncaptioned photos keep the generated alt |
| Year pages lacked the image-source disclosure the index had | Added to every year page |
| Background not hidden from assistive tech while the viewer was open | The viewer is now a native `dialog` opened with `showModal()`, which makes the rest of the page inert (the reviewer's suggestion 11); Tab also wraps within the three controls |
| Viewer controls unguarded under forced colours | `--on-brand-rule` and the viewer buttons covered in the forced-colours blocks |
| Static width and height on the viewer image did not match served ratios | Removed; the viewer sizes the image by CSS |
| Jump chips used a 36 px height | Now `--target` (44 px) |

Keyboard probe after the changes (`tooling/probe-lightbox.mjs`): Enter opens the viewer with focus inside; ArrowRight moves to the next photo and updates the live caption; Tab stays within the controls; Escape closes and returns focus to the photo link; "Show more" reveals the next 48 and moves focus to the first newly shown photo. All seven pages pass axe, overflow, focus, dropdown and theme checks at five widths in both themes.
